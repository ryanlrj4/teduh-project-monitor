# Optional KL full-universe proof

This directory contains reports generated by the original Kuala Lumpur
full-universe data-quality proof. That workflow remains available for research
through the explicit `legacy-kl-full-catalog` and `legacy-kl-validate` commands,
but it is not used by the dashboard, shortlist refresh, history, alerts, or
Discovery.

Normal operation is documented in [`../OPERATING_GUIDE.md`](../OPERATING_GUIDE.md).
