# Dashboard design reference

## Core tokens

| Role | Value |
|---|---|
| Primary red | `#E30613` |
| White background | `#FFFFFF` |
| Primary text | `#363B40` |
| Muted text | `#666B70` |
| Secondary surface | `#F6F6F6` |
| Border | `#DEDEDE` |
| Font stack | `Open Sans`, `OpenSans`, `Helvetica`, `Arial`, sans-serif |
| Standard corner radius | `5px` |

Red is reserved for primary actions, active navigation, focus states, and small
brand accents. Most headings and body copy remain charcoal on white, matching the
restrained hierarchy of the reference site. Open Sans is loaded as a web font;
the remaining fonts are local fallbacks if it is unavailable.
